# Fixed-mask codec feedback diagnostic

With the same legacy DIAG mask, `R2_OFFSET` produced slightly smaller
single-write and isolated future-readout errors than `LEGACY_P_PRE`, but
**3.20398× larger accumulated readout SSE** during recurrent equation replay.
This retrospective TRAIN diagnostic locates a disadvantage in repeated state
evolution under fixed operands. It does not identify the cause of the earlier
**16.34× whole-model KL regression** in [Results](RESULTS.md).

## Scope and reference fidelity

Run `RTPA_FIXED_MASK_CODEC_FEEDBACK_20260912_V1` completed **18/18 cases**:
six existing TRAIN documents × GDN layers 0/12/22, each with 256 tokens and
16 heads. Both codecs used the frozen legacy all-layer DIAG policy's selected
layer masks and the same 19,328-byte/head payload. There was no fitting, TEST
evaluation, mask search, or favorable-case filtering. Execution took
**47.136 seconds on CPU**, with **zero model forwards and zero GPU forwards**;
this elapsed time is diagnostic cost, not inference latency.

The reference is a zero-start **FP32 reconstruction of the layer recurrence**
from previously captured Native q/k/v/gates. Its states are not captured Native
states. Each codec carries its own quantized state through the same fixed
operand sequence; operands are not regenerated by a candidate-conditioned
whole model.

A separate reconstruction with BF16 storage after each write was compared
with saved Native reference readouts. It passed the frozen normalized-L2
tolerance of `0.0001` in **11/18 cases and failed in 7/18**; the maximum was
**0.00024249**. All seven failures remain in the results. Consequently this
study establishes equation-level observations, not Native execution parity.
The primary comparisons below use the reconstructed FP32 reference; the raw
observations also retain comparisons against saved Native readouts.

## Measured errors

SSE denotes a sum of squared errors. Ratios use the displayed positive
denominators without clipping; a zero denominator leaves a ratio undefined. The
single-write panel uses tokens 31/127/223: 54 shared snapshots, or 864
snapshot/head observations per codec. Their common reference-state energy is
8,777.07485753. Each isolated injection is propagated in FP64 through the next
32 fixed transitions, scoring only `t+1` through `t+32` with no later injections.
Recurrent updates remain FP32. The recurrent panel scores tokens `[16,256)`,
giving 69,120 head/token observations per codec; late readout uses `[128,256)`.
These counts describe coverage; the SSEs are sums, not per-observation means.

## Repeated encoding and reinforcing error

The codec-only repeat control applies 16 encode/decode writes to each shared
snapshot without recurrent token updates. Physical repeats include H32 round
trips. The affine-only control repeats transformed low groups without H32.
Drift is SSE between the sixteenth and first decoded values; normalization
uses each method's own first-write error against the original input.

| Control / codec | First-write error SSE | Step-16 drift SSE | Drift / first-write error |
|---|---:|---:|---:|
| Physical / legacy | 0.0748632142 | 0.0000000915083222 | 0.000122234% |
| Physical / R2 | 0.0708085406 | 0.00104663398 | 1.478118% |
| Affine-only / legacy | 0.0747102426 | 0.0000000915061733 | 0.000122481% |
| Affine-only / R2 | 0.0706555997 | 0.0000273633741 | 0.0387278% |

R2 drift is present in both controls. Their different coordinate sets and
transform arithmetic prevent treating their difference as an isolated H32
causal contribution. Neither control repeats a model's token updates.

For the realized pre-write error `e = Z_own − S_ref` and physical injection
`u = decode(encode(Z_own)) − Z_own`, the recorded identity is
`||e + u||² = ||e||² + ||u||² + 2⟨e,u⟩`. The cross term is positive in
**56,779/69,120 R2 observations (82.15%)**, compared with
**42,988/69,120 legacy observations (62.19%)**. This describes reinforcing
realized errors, not a pure temporal contribution or a causal share of KL.
The two methods already occupy different states. The maximum recorded
relative identity residual is `6.92294e-16` against tolerance `1e-10`.

Among 412,817 zero-containing transformed groups per codec, the mean absolute
decoded value nearest zero divided by stored scale is **0 for legacy and 0.2492463
for R2**. This descriptive grid statistic does not isolate zero-grid placement
from the other codec differences. Signed errors by value-position modulo 32
are retained to expose cancellation. No rounding, scale, offset, or mask was
changed to test a causal counterfactual. The study therefore neither explains
the full 16.34× TEST KL effect nor establishes a corrected deployment codec.

## Reproduction and evidence

From an installed source checkout with NumPy available:

```bash
python scripts/codec_feedback/aggregate.py \
  --run data/benchmarks/codec_feedback --out recomputed-codec-feedback
python scripts/codec_feedback/verify.py \
  --root . --out /tmp/codec-feedback-verification.json
```

The [expected summary](../results/codec_feedback/summary.json) is derived from
the included [case JSON/NPZ observations](../data/benchmarks/codec_feedback/cases).
The [freeze](../data/benchmarks/codec_feedback/freeze.json) binds protocol,
source, policy, and input identities; the
[execution receipt](../data/benchmarks/codec_feedback/execution.json) records
completion and actual operations. The numerical source is in
[scripts/codec_feedback](../scripts/codec_feedback). These commands reconstruct
and verify included evidence on CPU; they do not rerun capture-to-observation
execution or perform model inference.

The 18 parent capture `.pt` files remain **LOCAL_ONLY**, with hashes listed in
the freeze and scope in the [availability record](../data/benchmarks/codec_feedback/availability.json).
Full trace replay requires those exact captures and the recorded
source/environment; the public scalar observations alone cannot regenerate
them. Original codec and recurrence source bytes are unchanged. The
[independent scalar review](../results/codec_feedback/independent_scalar_receipt.json)
verified all 18 cases, the energy identity, snapshot controls,
operation counts, and 40 aggregate numerical fields without importing the
diagnostic or aggregator. That check does not establish Native parity or
independent whole-model replication.
