## DIAG endpoint signal and input dependence

The unchanged DIAG_SINGLE_WRITE policy has **14.8503% lower pooled Native-KL**
than B2_QUERY_PROMOTION on these six documents, and **0.012013652 nat/token lower
mean NLL**. KL and NLL each favor DIAG on **5/6 documents**; pytest is the adverse
case for both. These are descriptive endpoint-control comparisons from the
included results, not a new test, confidence interval or confirmatory pass.
The registered primary remains MIX versus B2, with **INCONCLUSIVE** unchanged.

This is the same model, R2_OFFSET/high8 codec and fixed single-write masks used
in the [earlier three-document screen](../results/fidelity_screen_20260915/tables.md),
not a refitted DIAG. That screen had 0.742% higher pooled KL than B2 despite
two document wins: uv and ripgrep improved, but Rich's larger worsening offset
their gains. Its NO_PROMOTION_FROM_SMALL_SCREEN decision remains. Rich and pytest
are retained; the panels are not pooled into a nine-document success claim.

The design combines signed low-to-high error reduction with finite-horizon
response weights from frozen key/gate-dependent GDN transitions and future query readouts. It uses
`sum_t W[t,i,i] p[t,i]`, not historical coherent `Kii+2ci` or its cross-write terms;
the transition itself is not diagonalized. B2 is a strong query-weighted,
output-aware control. See the [single-write definition](SINGLE_WRITE.md#single-write-definition-not-coherent-diag)
and [historical related-work boundaries](RELATED_WORK_AND_NOVELTY.md).

Different inputs induce different states, transitions and readouts, so a fixed
mask's benefit can plausibly vary with input. That is an interpretation, not
an identified row/layer cause. This post-hoc endpoint interpretation supports a
small-panel output-quality signal, not general superiority, task-accuracy,
latency or whole-VRAM gains, and does not resolve R2's legacy-relative regression.

## Fixed hypothesis and policy

Can a fixed, partial contribution from the detailed future-response score improve
B2's output preservation? B2 and DIAG both contain query information; they are
not independent estimators. Shrinkage, standardization and top-k are not claimed
as new mathematics, and variance reduction is a hypothesis, not an established cause.

The [configuration](../data/b2_mix025_20260916/run_config.json) binds all sources,
tokens, environment and policies. Reconstruct the same six TRAIN documents in
their original pooling order from the 108 included statistics:

- `p[t,i] = ||E_low[t,i]||² − ||E_high[t,i]||²`, retaining its sign.
- `B = pooled ENERGY × pooled query_square_sum/(6×240)`.
- `D = pooled sum_t W[t,i,i] p[t,i]`, the single-write score, not coherent K/c.
- For each layer/head vector, compute FP64 population mean/std across128 rows.
  `M=.75*(B−mu_B)/s_B+.25*(D−mu_D)/s_D`.
- Descending M, exact ties ascending row index, top8. No epsilon or approximate
  tie rule. Exactly zero B or D std uses the original B2 mask; nonfinite stops.

λ=.25 is the user's conservative first choice, not an estimated optimum and not
a six-B2/two-DIAG row quota. Normalization happens only on TRAIN; runtime loads
one final mask, with no B/D/W, normalization arrays, ensemble or extra state.
All original score/masks and nondegenerate λ=0/1 endpoints must reconstruct
exactly before any GPU evaluation. A fully identical endpoint policy stops as
NO_NEW_POLICY, not a duplicated new method.

The CPU construction found a distinct policy:288 heads, zero fallbacks;
132 protected slots changed versus B2 across112 heads (176 unchanged heads).
The policy preserves exactly8/128 rows at each head. This is not quality evidence.
The [receipt](../data/b2_mix025_20260916/policy_receipt.json) retains every head,
overlap, source binding and inherited calibration cost. Runtime bundle arrays
for B2/DIAG are byte-identical to their parent; the new bundle has its own hash.

## Input and execution design

Exactly6 new source documents ×1,024 tokens: two narrative chapters, two code
bodies, two technical guides. The [catalog](../data/b2_mix025_20260916/source_catalog.json)
records pinned source revisions/licenses. Use unmodified UTF-8 source, including
XHTML/Markdown/code headers: first1,024 IDs, add_special_tokens=False, no padding
or repetition. Selection order is group then casefolded repository/path; document
eligibility depends on length/provenance, never Native or candidate performance.
The [overlap audit](../data/b2_mix025_20260916/input_audit.json) covers accessible
historical records, not missing history or model-pretraining contamination.

Qwen3.5-0.8B-Base revision `dc7cdfe2ee4154fa7e30f5b51ca41bfa40174e68`, existing
RTX5080 and recorded environment only. BF16 weights/Native cache, FP32 recurrence,
all18 GDN layers/288heads. Unchanged R2_OFFSET/high8/UINT8/H32/group32/FP16 metadata,
eager per-token adapter, FLA fast path false, TF32 false, deterministic algorithms.
NATIVE, B2_QUERY_PROMOTION (primary), DIAG_SINGLE_WRITE and B2_DIAG_MIX025 receive
the same teacher-forced history with independent own caches. Deterministic
document-index method rotations are recorded; not fully counterbalanced timing.
No fitting, future runtime query, Native state injection, new task or codec.

## Endpoints and prospective decision

Full-vocabulary FP64 `Native||method` KL: [16,1024),6,048 positions/method.
Next-token NLL: [16,1023),6,042; final target is undefined, never filled with0.
Late KL: [512,1024),3,072. Report document and pooled means, p99 linear quantile,
largest ceil(.01×6048)=61 mean, maximum and paired harmful/beneficial mass.
Prefix256/512 summaries are from the same trajectories, not independent samples.

Primary MIX−B2 ΔKL and `1−mean(KL_MIX)/mean(KL_B2)`; zero denominator is undefined.
Secondary MIX−DIAG and all methods' Native-relative losses. Paired document
bootstrap:10,000 draws, NumPy PCG64 seed20260916, percentile95% linear intervals
for ΔKL, ratio-of-means reduction and ΔNLL. Never resample tokens/heads independently.
This six-document heterogeneous panel does not establish broad generalization.

1. Numerical failure/incomplete: preserve coverage and reason, no full-panel
   average from a successful subset.
2. ΔKL interval upper<0 and mean ΔNLL≤+.001nat/token: POSITIVE_SMALL_PANEL_SIGNAL.
3. Same KL condition but mean ΔNLL>+.001: QUALITY_TRADEOFF_OBSERVED.
4. ΔKL interval lower>0: ADVERSE_KL_SIGNAL_IN_SMALL_PANEL.
5. Otherwise INCONCLUSIVE.

The NLL threshold is a pragmatic screening choice, not noninferiority proof.
Five-percent KL improvement is a reference effect size, **not a pass gate**.
Report NLL intervals/tails even if primary KL improves. Do not add post-outcome
criteria, switch baseline or tune λ on these inputs.
